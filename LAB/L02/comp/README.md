# Parser Recursivo Descendente em Zig ⚡

Este repositório contém a implementação de um **Parser Recursivo Descendente** (Predictive Top-Down Parser) desenvolvido como material didático para a disciplina de **Compiladores**. 

O objetivo deste projeto é demonstrar de forma prática, limpa e eficiente como transformar uma sequência de *tokens* (gerada por um analisador léxico) em uma árvore de sintaxe correspondente, utilizando a linguagem **Zig**.

## 🚀 Por que Zig?

Zig foi escolhida para este projeto por oferecer:
* **Sintaxe robusta e legível:** Ideal para o ambiente acadêmico.
* **Ausência de fluxo de controle oculto:** O que você lê é exatamente o que é executado.
* **Gerenciamento de memória explícito:** Excelente para ensinar como os nós da AST (Árvore de Sintaxe Abstrata) são alocados e desalocados na memória.
